# Source provenance

The scripts were extracted from the authors' original `NIGER` Google Colab notebook, stored under the personal Drive account's `Colab Notebooks` directory on 17 November 2026. The publication figure/table generator matches the notebook code that generated the nine figures and twelve tables, except for environment-variable input/output location support and disabling interactive display by default.

Included computational source stages: 04, 05, 06, 07, 08, corrected 09, 10A, 10B, 11, 12 and 13. The initial superseded Step 09 draft was deliberately omitted. Analyses were executed previously in the author's Colab environment, but this extraction and wrapper have not been independently run against Drive data in this package's build environment. Tests here cover only the preflight utility.

Source-to-raster comparisons (Steps 15 and 16G) were executed and reported by the authors in Colab; their complete input/output tables remain in `15_Source_To_Raster_Verification` and `16_ERA5Land_Surface_Provenance` in Drive and should be deposited separately with provenance metadata before claiming an independently rerunnable provenance check. Do not imply these checks are recomputed by `run.py`.
