# Data availability before public release

RSASE's author guide requires the research data to be deposited in an appropriate repository and linked during submission, or an explicit explanation if sharing is impossible. The authors must decide and verify that an accessible repository has actually been created. Do not publish unlicensed third-party data or private credentials.

Suggested statement **only after completing a genuine deposit**:

> The analysis scripts are available at [actual GitHub repository URL]. Derived data and verification tables are available from [actual repository name and persistent DOI]. Original ERA5, CHIRPS, ESA land-cover and NEX-GDDP-CMIP6 datasets are distributed by their respective providers under their applicable terms.

Until a deposit exists, do not substitute placeholders in the manuscript. Record any restrictions and explain why sharing is not possible if an exception is required.
